## Bronze transformations (applied when reading → Silver)

These happen in `01_load_and_merge.py`, not in Bronze storage:

1. Concatenate 7 yearly Shopify exports
2. FX conversion to SGD (MY/HK → SGD at 5-year average rates)
3. Parse dates to `Asia/Singapore`
4. Classify product category from handle
5. Classify channel from tags / UTM
6. Build `orders`, `lines`, `customers` canonical tables

**Nothing is deleted from Bronze** — Silver is a derived copy.
